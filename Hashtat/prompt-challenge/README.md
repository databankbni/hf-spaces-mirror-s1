# Prompt Challenge

Learn to write better AI prompts through short, practical challenges — in English or Arabic.

Static frontend hosted on Hugging Face Spaces. Prompt evaluation is proxied through a small
Cloudflare Worker that holds the Groq API key server-side, so the key is never exposed to the browser.
