# 🐱 LongCat Video Avatar 1.5 - Hugging Face Space Demo

This Hugging Face Space hosts an interactive demo for **LongCat-Video-Avatar-1.5**, an audio-driven human video avatar generation model created by the Meituan LongCat team.

## Features
- **Lip Synchronization**: Uses Whisper-Large for high precision audio-lip sync.
- **High Temporal Stability**: Generates smooth, realistic video avatar animations from a single portrait photo and audio track.
