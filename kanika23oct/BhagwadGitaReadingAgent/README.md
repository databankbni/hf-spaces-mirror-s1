# Bhagwad Gita Reading Agent

> **Status:** Planning stage. Not yet implemented. See [PLAN.md](PLAN.md) for the design.

An agent that reads the Bhagavad Gita to you — Sanskrit shloka followed by English
translation — for a configurable wall-clock window (min 10 minutes per session).
Bookmarks your position by email, and (optionally) sends a daily reminder to
keep you on track.

## Roadmap

The full plan, including phase-by-phase build order and verification steps, lives
in **[PLAN.md](PLAN.md)**. The current placeholder `app.py` simply renders
`PLAN.md` so the plan is browsable on the Space until real code lands.
