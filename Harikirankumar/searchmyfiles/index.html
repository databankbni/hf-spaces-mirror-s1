How to use SearchMyFiles

Use this quick loop if you're opening the app for the first time. It demonstrates the most common workflow from PDF preview to OCR output to region-based research tools.

  1. Upload a PDF or image and keep the viewer in Full Page mode.
  2. Click Extract Text to OCR the whole page first.
  3. Read the extracted content in the Extraction Panel on the right.
  4. Switch to Region Select for a smaller area and drag around the exact text you want.
  5. Use the popup actions to launch Web Search or send that selection to Copilot Chat.
