# LongCat-Video-Avatar 1.5 Demo

Audio-driven human video generation with LongCat.

## Usage

1. Upload an audio file (MP3/WAV)
2. Upload the input JSON specifying avatar and parameters  
3. Click "Generate Video" to process

## Model

[LongCat-Video-Avatar 1.5](https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.5) - Audio-driven human video generation framework.

**Note:** Full inference requires GPU. This demo shows the interface - for actual video generation, deploy on GPU hardware.
