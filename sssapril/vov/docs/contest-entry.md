# TRAE AI 创造力大赛 · 报名帖

**【标签】** 生活娱乐

**【标题】** 生活娱乐 + vov — 可编排的多 Agent 协作平台：让 AI 像群演一样为你协作

---

## 1. 创意名称 + 创意介绍

**创意名称**：vov

**想解决什么问题**：现有 AI 工具要么太固定（预设工作流无法偏离），要么太自由（单聊无结构）。用户需要的是一个**灵活度可调的多 Agent 工作台**——同一套机制，能做严格工作流，也能做完全自由协作。

**为什么会想到做这个**：我们想做通用多 Agent 工作台。系统只提供机制（提示词、Skill、群聊、任务、Chain、表达力组件），不绑定具体玩法。用户通过项目结构约束流程——约束多就是工作流，约束少就是自由协作。AI 可自主推进，也可和人交互。

**大概是什么产品**：桌面应用 / Web 端。一个多 Agent 工作台，提供"机制层"+"表达力层"两层通用能力，用户在上面创建项目、定义玩法、编排 AI 协作。名字 vov 像人脸，象征"电子人"。

---

## 2. 目标用户及痛点

**面向哪些用户**：
- 想"编排 AI 团队"的人（创作者、研究者、桌游爱好者）
- 对"AI 群聊玩法"感兴趣的人
- 想要 AI 输出可视化结果而非纯文字的人

**使用场景**：
- **狼人杀**：5 人局，AI 法官主持，任务隔离身份（约束型工作流）
- **小说写作**：8 阶段流水线，8 Agent 协作，目标 50 万字长篇（半自动推进）
- **酒馆**：多角色扮演闲聊（完全自由协作）
- 未来可扩展：剧本杀、D&D 跑团、论文协作、产品设计等

**当前痛点**：
- 现有 AI 工具要么固定工作流，要么纯聊天，缺少灵活度可调的中间地带
- 缺少"角色分工+流程管理"的通用框架
- AI 输出只能看文字，无法渲染结构化数据

---

## 3. 价值与意义

**效率提升**：
- 第一次把"灵活度可调"做成多 Agent 工作台的核心设计，一套机制适配固定工作流/半自动/完全自由协作三种模式
- 通用能力 + 表达力层，搭建出"机制层操作系统"，孵化出狼人杀、小说写作、酒馆等多种玩法
- 模板系统 + 引导 Agent，让新手也能快速上手，从空白到完整项目只需一句话

**社会价值**：
- 探索 Agent 时代的"人机协作"新范式，用户从"操作者"升级为"导演"
- 通用框架能孕育整个"AI 玩法生态"，用户可分享模板形成社区

## 4. 创意方案补充（设计思路）

### 分层架构

```
┌─────────────────────────────────────┐
│ L4 应用层：用户自建玩法            │
│   - 狼人杀 / 小说写作 / 酒馆...   │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│ L3 表达力层：AI 输出能力增强       │
│   - render_view 通用渲染组件       │
│   - 地图编辑器（小说衍生）         │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│ L2 通用能力层：协作机制            │
│   - Agent / Group / Task / Chain   │
│   - Skill / Tool / Memory          │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│ L1 引擎层：自研 agentflow SDK      │
│   - InfoPacket 流转                │
│   - Chain 隔离 / 上下文换链        │
└─────────────────────────────────────┘
```

### 关键技术

- `render_view` 让 AI 在群聊中"边说边画"，把表格/列表/地图/时间线等结构化数据直接渲染为可视化面板
- 地图编辑器支持方格/六边形网格、领地系统、子地图层级嵌套
- agentflow SDK 的 Chain 隔离机制保证多角色上下文不污染

### 模板系统 + 引导 Agent

- **保存为模板**：用户完成项目后，一键保存为模板
- **导出/分享模板**：模板可导出文件，分享给其他用户
- **从模板导入**：新用户从模板一键创建项目
- **引导 Agent**：用户描述"我想做什么"，引导 Agent 帮忙生成完整项目结构
