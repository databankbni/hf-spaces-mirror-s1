# render_view 最佳实践

## 视图选择原则

1. **先想清楚要传达什么信息**，再选视图
2. 一张图只传达一个核心信息
3. 用颜色编码状态（绿=好，红=差，蓝=中性）
4. 数字要有上下文（同比、环比、目标值）

## 视图选择速查

| 场景 | 推荐视图 | 原因 |
|-----|---------|------|
| 任务列表 | table | 支持排序、筛选、分页 |
| 角色档案 | list (grid) | 卡片式更直观 |
| 故事大纲 | tree | 层级关系清晰 |
| 世界观设定 | document | 长文本 + 目录 |
| 角色对比 | card | 并排对比 |
| 项目进度 | stat + table | 概览 + 明细 |
| 剧情时间线 | timeline | 时间序列 |
| 地理关系 | map | 空间布局 |

## 常见错误

- ❌ 用 document 展示 3 条数据 → 应该用 table 或 list
- ❌ 用 table 展示长文本 → 应该用 document
- ❌ 一次输出太多视图 → 选择最关键的 1-2 个
- ❌ map 的 cells 重叠 → 会导致显示异常

## 调用技巧

- 先给结论，再给数据
- title 要有信息量（"2024年Q1销售数据"而非"数据"）
- description 可以补充说明数据来源或口径
