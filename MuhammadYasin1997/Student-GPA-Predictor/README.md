# Student GPA Predictor

A Machine Learning application that predicts student GPA using a Linear Regression model.

## Features

- Linear Regression Machine Learning Model
- Gradio User Interface
- Joblib Model Loading
- Free Cloud Deployment

## Input Features

The model uses:

- Parental Education
- Study Time Weekly
- Absences

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Gradio
- Joblib

## How It Works

1. User enters student information.
2. The saved Linear Regression model processes the inputs.
3. The application returns the predicted GPA.
