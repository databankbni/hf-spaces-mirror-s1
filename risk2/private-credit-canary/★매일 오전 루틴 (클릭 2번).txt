매일 오전 루틴 (클릭 2번)
코랩 실행 + Drive에서 7개 CSV 다운로드 → data/ 자동 저장
start_dashboard.bat 더블클릭 → streamlit 시작 + 브라우저 자동 오픈
첫 실행 시 주의사항
처음 .bat 더블클릭 시 Windows 가 보안 경고를 띄울 수 있습니다:

"Windows의 PC 보호 — Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 차단했습니다."

→ 추가 정보 → 실행 클릭하면 신뢰 목록에 등록되어 다음부터는 바로 실행됩니다.

종료 방법
streamlit 콘솔 창에서:

Ctrl + C 한 번 → "Y" 입력
또는 Ctrl + C 두 번
또는 콘솔 창 자체 닫기 (X 버튼)
PC 자동 종료 시에는 자동으로 프로세스가 끝나므로 종료 작업 따로 안 해도 됩니다.

참고 — sync_data.bat 은 언제 쓰나
자동 sync (tools/sync_data.py) 가 streamlit 시작 시 호출되니 평소엔 사용할 일 없습니다. 다만:

streamlit 떠있는 도중에 새 데이터 받았는데 즉시 반영하고 싶을 때 (10분 캐시 기다리기 싫을 때)
또는 streamlit 안 켜고 data 폴더만 수동 정리하고 싶을 때
이런 보조 용도로 남겨둔 것입니다. 일상에선 start_dashboard.bat 하나만 쓰시면 됩니다.

추가 권장
작업 표시줄에 start_dashboard.bat 을 고정해두면 매일 클릭 한 번으로 시작 가능
