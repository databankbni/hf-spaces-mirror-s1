# Verified Student Pathway Agent

**Evidence-backed course guidance, eligibility checks and safer study pathways.**

This public Space demonstrates how prospective students can receive sourced course answers, a preliminary check against published entry conditions and a safer next-step pathway.

It uses fictional demonstration data. It does not make admission decisions, approve credit, provide visa advice or promise employment outcomes.

## Public demonstration boundary

The repository contains a functional public shell and sample rules only. Production document ingestion, LLM Wiki construction, provenance services, rule extraction, constraint services, full audit logging, evaluation dashboards, human approval workflows and reusable deployment templates are excluded from the public release.
