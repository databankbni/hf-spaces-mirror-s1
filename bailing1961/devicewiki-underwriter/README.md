# DeviceWiki Underwriter

Photograph a used phone; get an underwriting decision you can audit. The AI
vision model only describes damage in a closed vocabulary; the verdict comes
from a pre-compiled rule base machine-checked for consistency and
completeness, with every reason cited to its source. Uncertainty routes to
human review, never to silent approval.

Live demo in this Space; plain-language case note and honest limitations in
the About tab. Built on a private verification core (document ingestion,
LLM-Wiki knowledge structure, rule compilation, constraint checking, audit
and evaluation tooling) that is not part of this repository.
