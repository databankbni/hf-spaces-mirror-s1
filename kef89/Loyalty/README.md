# Talk It Through

Regal Rewards internal training — Tool 1 of 3.

A standalone, client-side practice tool for team members:

- **Learn & Practice** — chat-style objection practice (keyword-matched, all real approved rebuttals) plus a streak-gated tier-knowledge quiz
- **Resource Library** — searchable guest categories and tier quick facts
- **Quick Reference** — printable tier comparison card and a shift-prep checklist

No backend, no external calls, no data collection — everything runs in the browser.
