# FastAPI Lab

A focused tutorial and practice playground for learning FastAPI through short lessons, interactive exercises, and request/response traces.

## Included

- Progressive FastAPI lesson path
- Code exercises with hints and validation
- HTTP request/response visualizer
- Searchable quick reference
- Browser-local progress tracking

This free Static Space keeps the learning experience entirely in the browser. The trace panel uses a simulated response; the companion Docker/FastAPI project is preserved in the workspace at `/workspace/fastapi-lab` for use when Docker Spaces are available.
