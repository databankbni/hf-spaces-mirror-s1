# Ollama Cloud Bridge
This is a modular bridge for connecting AI agents to cloud-hosted Ollama models.

## Features
- Fully compatible with the standard Ollama API
- Routes requests to cloud-hosted Nemotron and GPT-OSS models
- High-performance FastAPI implementation
