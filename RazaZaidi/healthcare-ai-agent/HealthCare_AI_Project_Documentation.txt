This is a full-stack AI Healthcare Chatbot built using:
- LangChain + LangGraph for multi-agent AI routing
- Groq API for fast free LLM responses
- NLU (Natural Language Understanding) for intent classification
- FastAPI for backend REST API
- SQLite for data storage
- HTML/CSS/JS for frontend website

Architecture:
User → Website (HTML/JS) → FastAPI Backend → NLU Classifier → LangGraph
→ Groq LLM → Response → Save to SQLite DB → Show to User

What is NLU?
NLU is a local AI model that INSTANTLY detects what the user wants
WITHOUT calling any API. It runs on your computer for free.

How it works:
User types message → NLU checks intent → Routes to correct agent
Example: "I have chest pain" → NLU detects "emergency" in 0.001 seconds

Algorithm Used:
1. TF-IDF Vectorizer
   - Converts text into numbers (vectors)
   - ngram_range=(1,2) means it looks at 1 and 2 word combinations
   - Example: "chest pain" is treated as one feature

2. Logistic Regression Classifier
   - Learns patterns from training data
   - Predicts which intent matches the input
   - Returns confidence score (0.0 to 1.0)

3. Pipeline
   - Combines TF-IDF + Logistic Regression
   - Trained once, saved as model.pkl
   - Loads instantly when needed

What is LangGraph?
LangGraph is a framework for building multi-agent AI systems.
It creates a workflow (graph) where different agents handle different tasks.

Agents in This Project:
┌──────────────┬──────────────────────────────────────────────────────────────┐

├──────────────┼──────────────────────────────────────────────────────────────┤
│ Triage Node  │ Router - detects intent and routes to correct agent          │
│              │ Handles emergencies directly                                  │
├──────────────┼──────────────────────────────────────────────────────────────┤
│ Researcher   │ Academic AI healthcare researcher                             │
│ Node         │ Searches web, gives formal academic responses                │
│              │ Saves findings to files in artifacts folder                   │
├──────────────┼──────────────────────────────────────────────────────────────┤
│ Lifestyle    │ Personal health and wellness coach                            │
│ Node         │ Gives friendly advice on diet, sleep, exercise               │
│              │ Searches web for tips and recipes                             │
├──────────────┼──────────────────────────────────────────────────────────────┤
│ General      │ Handles greetings and general questions                       │
│ Node         │ Friendly introduction and general health info                 │
└──────────────┴──────────────────────────────────────────────────────────────┘

Graph Flow:
Message → Triage Node → router() function
   If emergency → respond directly → END
   If research  → Researcher Node → END
   If lifestyle → Lifestyle Node  → END
   If general   → General Node    → END

What is Groq?
Groq is a cloud AI service that runs Large Language Models (LLMs)
at extremely high speed using custom hardware called LPUs.

Default Model: openai/gpt-oss-20b
- Configurable through the GROQ_MODEL environment variable
- Selected from models available to the deployed Groq project
- Replaces Groq's retired Llama 3.x developer-tier models

Why Groq?
- Fastest free LLM available
- 14,400 requests/day free tier
- No credit card needed
- Works perfectly with LangChain

How it is used in this project:
from langchain_groq import ChatGroq
llm = ChatGroq(model=os.getenv("GROQ_MODEL", "openai/gpt-oss-20b"), api_key=GROQ_KEY)
response = llm.invoke([SystemMessage(...), HumanMessage(...)])
