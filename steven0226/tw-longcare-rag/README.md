# 台灣長照法規 RAG 諮詢系統

家中長輩申請長照服務時，我發現相關規定分散在好幾部法規裡——母法、給付辦法、
機構管理辦法、老人福利法彼此交錯，自己查證很花時間。這個工具用白話中文提問，
回答會標明出自哪一條法規（點擊可展開原文查證），查不到明確法源就誠實說查不到。

檢索使用台灣在地開源模型（TAIDE embeddinggemma-GTAIDE）；這個線上版本受限於
免費 Space 硬體，回答固定使用雲端模型，本機執行可改用台灣在地生成模型
（TAIDE 12B）——完整原始碼、模型選型對照與評估結果另見專案說明。

> ⚠️ 本工具為非官方個人專案，僅供參考。正式資訊請以衛生福利部公告與
> **1966 長照服務專線**為準。

## 使用方式

直接在下方輸入框用白話提問，例如「阿嬤請看護政府有補助嗎」。「進階設定」
可切換雲端回答模型；「引用來源與相關條文」可查看系統實際檢索到的法條出處。

> 💤 免費 Space 硬體閒置一段時間會休眠，之後第一次載入需要重新建立索引，
> 實測約 **2 分鐘**（115.4 秒，2026-07-23 於 CPU Basic 硬體實測，含重新
> 下載 embedding 模型），之後的提問就會恢復正常速度，請耐心等候。
