Architecture Addon for Blender

Six one-click fixes for architecture models imported into Blender: unit scale, origins, exporter hierarchy, padded renaming, collection grouping and a recursive purge. Run the panel top to bottom.

What it does

Apply Import TransformsBake the unit scale and rotation a CAD import left behind, before bevel and boolean go wrong
Origins To Object CentreImported doors and furniture all pivot on the world origin - give each one its own centre
Unlink Exporter HierarchyCut the empties the exporter parented a storey to, without one wall moving a millimetre
Rename To Prefix And NumberType a prefix once and get Wall_001, Wall_002 - padded and sortable, not dot suffixes
Selection To New CollectionMove the selected storey or trade into a fresh collection named from the same prefix field
Purge What The Import LeftAfter deleting half the import, drop the orphan meshes, materials and images still in the file

How to install

  1. Blender 4.2 or newer: Edit > Preferences > Add-ons > Install from Disk…
  2. Pick the downloaded .zip — do not unpack it first.
  3. Open the 3D viewport sidebar with N and find the Architecture tab.
