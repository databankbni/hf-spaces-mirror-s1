# Architecture Addon for Blender

The six fixes every imported CAD or IFC model needs, in the order you run them: in stock Blender they are about 20 clicks across three Object submenus, two popups and the File Clean Up menu - here they are six buttons in one sidebar tab, on the whole selection at once.

Runs entirely in your browser. Nothing is uploaded, nothing is stored.
