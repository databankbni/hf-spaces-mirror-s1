# Recovering Force-Related Actions for the React Tactile Dataset

Two methods implemented and evaluated on [yxma/React](https://huggingface.co/datasets/yxma/React):
photometric-stereo depth -> Winkler normal force (pseudo force labels), and
DexForce-style force-informed position targets. Includes a documented negative
result (FEATS does not transfer to markerless gel), self-designed evaluations,
and a debug log. See the rendered page.
