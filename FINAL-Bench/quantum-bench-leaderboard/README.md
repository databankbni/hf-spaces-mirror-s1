# FINAL-Bench Quantum

An open, **neutral** benchmark suite for quantum-computing methods. The first event is a
**QEC decoder** leaderboard on a rotated surface code (Stim, circuit-level noise).

- **Track A** — head-to-head decoders measured on one frozen public test set (✓ VERIFIED).
- **Track B** — published references from groups worldwide; setups differ and are **not**
  directly comparable (REPORTED).

All methods are evaluated under identical public protocols. This is a decoder benchmark —
**no quantum-advantage claims** are made. Submit your decoder via the **Submit** tab; entries
are reviewed manually and, once reproduced on the frozen test set, added to Track A.
