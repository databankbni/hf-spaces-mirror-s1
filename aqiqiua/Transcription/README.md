# Транскрайбер видео → TXT

Веб-приложение: вставляешь ссылку на YouTube **или** загружаешь видео/аудио —
получаешь TXT с логическими абзацами, таймкодами и разделами. Работает с телефона.

## Как это устроено

1. **Ссылка на YouTube** → сначала пробуем готовые субтитры.
   Если субтитров нет — скачиваем аудио (`yt-dlp`) и распознаём речь.
2. **Загруженный файл** (MP4, MOV, MP3…) → извлекаем аудио (`ffmpeg`), распознаём речь.
3. Распознавание речи: **faster-whisper прямо на сервере** (бесплатно, без ключей).
   Если задан `GROQ_API_KEY` — используется Groq Whisper (быстрее).
4. Форматирование: без ключей — абзацы по паузам; с `ANTHROPIC_API_KEY` — умные
   абзацы и главы через Claude.
5. Отдаём готовый `.txt`.

**Работает вообще без ключей.** Ключи — только для скорости (Groq) и качества
форматирования (Claude).

## Секреты (Settings → Secrets на Hugging Face) — все необязательны

| Переменная | Зачем |
|---|---|
| `ANTHROPIC_API_KEY` | умные абзацы + главы (иначе — простые абзацы по паузам) |
| `GROQ_API_KEY` | ускоряет распознавание файлов (иначе — локальный Whisper, медленнее) |
| `SUPADATA_API_KEY` | YouTube-ссылки (субтитры тянутся со стороннего сервиса — обходит блокировку YouTube с датацентра). Без него ссылки на HF не работают. |

Прочее для Supadata: `SUPADATA_MODE` (`native`/`generate`/`auto`, умолч. `auto`),
`SUPADATA_FETCH_TITLE` (`0` — не тянуть название видео, экономит 1 кредит).

Экономия на Claude: `FORMAT_MODE` (`auto`/`rewrite`/`breaks`, умолч. `auto`).
`breaks` — Claude возвращает только точки разбивки на абзацы (в ~10 раз меньше
выходных токенов), подходит для субтитров с готовой пунктуацией; `rewrite` —
полное переписывание (для сырых субтитров/Whisper); `auto` — выбирает сам.

> Прямой доступ к YouTube с Hugging Face заблокирован (и даже через жилой прокси —
> проверено). Поэтому для ссылок используется Supadata. Прокси-переменные
> (`WEBSHARE_*`, `PROXY_URL`) в коде остались как задел на случай другого хостинга.

Прочие: `WHISPER_MODEL` (`tiny`/`base`/`small`/`medium`, по умолчанию `small`),
`FORMAT_MODEL` (`claude-haiku-4-5`), `SUBTITLE_LANGS` (`ru,en`).

**Прокси для YouTube** (иначе ссылки блокируются с датацентра). Задай ЛИБО пару
Webshare-секретов, ЛИБО generic-URL:

| Переменная | Зачем |
|---|---|
| `WEBSHARE_PROXY_USERNAME` + `WEBSHARE_PROXY_PASSWORD` | «жилой» прокси Webshare (рекомендуется) |
| `PROXY_URL` | любой прокси в формате `http://user:pass@host:port` |

> ⚠️ Groq и Anthropic блокируют создание ключа из некоторых стран. Но **сам Space
> стоит в датацентре США/ЕС**, поэтому созданный (напр. через VPN) ключ работает
> без ограничений. А базовый режим вообще не требует ключей.

## Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # плюс системный ffmpeg
export ANTHROPIC_API_KEY=...  GROQ_API_KEY=...
python app.py                            # http://localhost:7860
```
