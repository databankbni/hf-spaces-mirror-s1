📖 ข้อมูลเชิงเทคนิคและคู่มือการใช้งานระบบ

1. โครงสร้างฟีเจอร์ของโมเดล (10 Features Vector)

โมเดล Machine Learning (Gradient Boosting) ได้รับการฝึกสอนด้วยฟีเจอร์หลักทั้งหมด 10 ตัว ดังนี้:

['ra', 'dec', 'b', 'l', 'phot_g_mean_mag', 'bp_rp', 'c_star', 'ruwe', 'teff_gspphot', 'logg_gspphot']

2. การประมวลผลข้อมูลและ Photometric Excess Ratio (C*) Outliers

ระบบจะ ไม่ทำการ Drop Row ข้อมูลออก แม้ดาวดวงนั้นจะมีค่า C* ผิดปกติหรือเป็นสัญญาณรบกวน เพื่อรักษาความสมบูรณ์ของข้อมูลประชากรดาว 100% โดยระบบจะทำการพยากรณ์ค่า $M_G$ และคำนวณสเปกตรัมให้โดยอัตโนมัติ พร้อมทั้งติด Flag แจ้งเตือนในกรณีที่ดาวมีแนวโน้มเป็น Stellar Outliers

3. วิธีการดึงข้อมูลจาก Gaia DR3 Archive (ADQL Query)

สำหรับชุดข้อมูลที่ใช้ฝึกสอนและทดสอบระบบ จะทำการสืบค้นผ่านระบบ ESA Gaia Archive โดยใช้คำสั่ง ADQL ดังนี้ 

                        
                                SELECT TOP 80000                           -- กำหนดจำนวนดาวฤกษ์ที่ต้องการศึกษา
                                    source_id, ra, dec, b, l, 
                                    phot_g_mean_mag, phot_bp_mean_mag, phot_rp_mean_mag,    
                                    (phot_bp_mean_mag - phot_rp_mean_mag) AS bp_rp,
                                    phot_bp_rp_excess_factor, parallax, parallax_error, ruwe,
                                    visibility_periods_used, teff_gspphot, logg_gspphot
                                FROM gaiadr3.gaia_source
                                WHERE phot_g_mean_mag > 6                  -- กำหนดช่วงโชติมาตรปรากฏที่ต้องการศึกษา
                                AND phot_g_mean_mag <= 18
                                AND ABS(b) > 20                            -- กรองหลบฝุ่นระนาบดาราจักร (|b| > 20 deg)
                                AND phot_bp_mean_mag IS NOT NULL
                                AND phot_rp_mean_mag IS NOT NULL
                                AND phot_bp_rp_excess_factor IS NOT NULL
                                AND parallax_over_error > 5                -- ควบคุม Parallax (> 5)
                                AND ruwe < 3                               -- ควบคุม Astrometric Quality
                                AND visibility_periods_used > 8            -- เลือกข้อมูลที่ผ่านการสังเกตุซ้ำ
                                AND logg_gspphot IS NOT NULL               -- กำหนดให้ระบุค่าความโน้มถ่วงที่ผิว
                                AND teff_gspphot IS NOT NULL               -- กำหนดให้ระบุค่าอุณหภูมิพื้นผิว

4. การ Export ผลลัพธ์ CSV

ผู้ใช้สามารถดาวน์โหลดไฟล์สรุปผลทำนายทั้งหมดเป็นไฟล์ CSV เพื่อนำข้อมูลค่า M_G, Luminosity Ratio, Distance, Parallax และ Spectral Class ไปวิเคราะห์ต่อในระบบดาราศาสตร์ภายนอกได้ทันที
