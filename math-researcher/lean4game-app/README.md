Public host for the lean4game relay, serving the Natural Number Game (`nng4`)
and the Set Theory Game (`STG4`).

- Games API: `/api/games`
- WebSocket: `/websocket/g/<owner>/<repo>` (e.g. `/websocket/g/leanprover-community/nng4`)
