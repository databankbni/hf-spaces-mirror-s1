# Scene Text Super-Resolution Demo

Interactive companion to the MSc dissertation:

**Deep Learning for Text Enhancement: Improving Text Readability in Degraded Images using Super-Resolution Methods**

The demo presents selected precomputed outputs from the TextZoom and CUTE80 experiments.

Methods compared:

- Bicubic interpolation
- Real-ESRGAN
- TSRN
- C3-STISR

The dissertation evaluates a controlled 2x super-resolution task:

- LR input: 64 x 16
- SR output: 128 x 32

No model was trained or fine-tuned as part of the dissertation.
