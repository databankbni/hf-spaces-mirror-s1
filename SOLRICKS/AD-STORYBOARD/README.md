# AD-STORYBOARD

**From brief to shot list.**

A browser-based ad storyboard helper for AI video production.

Features include timed shot breakdowns, camera direction, AI-video prompt drafts,
production notes, and **PDF / Markdown / JSON export**.

> Runs locally in your browser. No brief is uploaded.
