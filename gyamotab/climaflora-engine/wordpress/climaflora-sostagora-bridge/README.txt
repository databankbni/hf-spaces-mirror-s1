ClimaFlora — Pont Sostagora 1.0.0

Installation manuelle :
1. Téléverser le dossier climaflora-sostagora-bridge dans /wp-content/plugins/.
2. Activer « ClimaFlora — Pont Sostagora » dans WordPress.
3. Aucun secret supplémentaire n’est nécessaire.

Le plugin :
- émet un code aléatoire à usage unique valable 120 secondes ;
- vérifie le méta WordPress sa_sostagora_access au moment de l’échange ;
- synchronise les ajouts et retraits d’accès vers ClimaFlora ;
- fournit le shortcode [climaflora_sostagora_link].

URL de diagnostic après activation :
https://shugoan.com/wp-json/climaflora/v1/status
