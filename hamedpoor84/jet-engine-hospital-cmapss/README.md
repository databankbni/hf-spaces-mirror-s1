# Jet Engine Hospital

Interactive NASA C-MAPSS dashboard using the locked outputs of the submitted
Streamlit pipeline. The free Hugging Face account cannot create compute-backed
Streamlit/Docker Spaces, so this public Space is a browser-side deployment fallback.

The dashboard includes FD001 and FD003 engine/cycle selection, RUL with a 90%
interval, calibrated 10/20/30-cycle risks and thresholds, anomaly percentile and
persistence, a traceable action, and reproducibility metadata.
