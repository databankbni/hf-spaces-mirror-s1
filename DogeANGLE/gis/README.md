# GIS-Review v2.0 — 专业课 AI 复习助手

GIS（地理信息系统）和遥感专业课的智能复习应用。基于阿里云百炼 DashScope RAG 平台，以教材知识库为后盾，提供 AI 问答、闪卡记忆、自动出题、模拟考试、学习统计、跨端同步等功能。v2.0 新增**积分经济与主题商店**：积分拆分为「可花余额」与「终身累计」（等级只看累计，消费只扣余额）；「我的」页可购买**连胜保护卡**（80 积分/张、上限 2，断档结算时每漏 1 天自动扣 1 张保连胜），并修复连胜"装死漏洞"（跳过整天不开 app 连胜永不清零），按真实 gap 天数结算；🎨 改为**主题商店面板**（13 套 swatch 预览、点击应用），新增 4 套积分解锁限定主题（星轨/石墨/晨雾/金榜，各 150 积分，随云同步），并修正现有主题配色（暖棕族主色改赤陶/琥珀、亮色主题正文降饱和更护眼）。v1.5 新增**正反馈庆祝系统**：闪卡积分/连击、满分庆祝、每日任务、达标与里程碑庆祝、音效（可关）。v1.6 新增**自定义 Prompt 编辑器**：在「我的」页可整段改写全部 AI 提示词（问答/闪卡/判题/出题/冲刺/指南），占位符运行时替换，可一键恢复默认并随云端同步。v1.7 修复「我的」页数据安全与统计正确性：同步时间戳体系修复（杜绝下载静默覆盖本地新数据）、覆盖确认反转、全部本地数据解析崩溃防护、年份视图/跨午夜结算/每日目标级联修正、闪卡缓存不再上云，并修复徽章触发逻辑（章节徽章按真实掌握率触发、连胜里程碑兼容老数据）。v1.8 新增**记忆衰退系统**：完成度随时间按遗忘曲线回落（第 N 轮 7/14/28/56/90 天封顶），复习推进轮次、轮次越高衰退越慢；衰退词重答即时巩固反馈，章完成庆祝与轮次里程碑徽章（第 3/7/10 轮）。v1.9 修复「我的」页计时与今日学习：学习时长秒表秒级落盘（刷新后从原秒数续计，不再退回整分）、跨天/刷新后不再归零、今日学习与每日任务「学习 N 分钟」进度恢复正常；并为记忆衰退系统新增**手动「再来一轮」**——学习进度页每章可一键清空该章掌握进度（轮数保留），重新掌握到 80% 即晋升下一轮，不再苦等 7 天衰退。另修复 v1.7 引入的 safeJSON 缺失 key 返回 null 的潜在崩溃。v1.9.2 修复判题「长 prompt 稀释检索」：AI 判题/模拟考试判题改为两步——先以纯题目预检索教材上下文（短 query 召回精准、结果走服务端缓存），再把【教材知识上下文】注入判题模板评分，1100 字长 prompt 不再参与检索；知识库无对应内容的考点由预检索如实返回【未检索到该考点】，前端标记「教材未覆盖」、不评分不标掌握，杜绝 AI 用通用知识糊弄。v1.9.3 新增**缓存管理**：服务端缓存条目按用途打标签（问答/判题预检索/判题评分/学习指南/考前冲刺/闪卡/AI出题），`skip_cache:true` 请求不再写服务端缓存（修掉判题/冲刺唯一回答无限膨胀缓存的 bug），`GET /api/cache` 返回按用途计数、`DELETE /api/cache?purpose=` 支持定向清除；「我的」页新增「🧹 缓存管理」区块——服务端缓存按用途逐项清除、本地缓存（回答/闪卡/对话/指南/冲刺/出题记录）逐项清除，每项清除前 confirm 明确说明，杜绝被污染的检索结果（如 RAG 阈值调错产生的「未检索到该考点」）永久废掉关键词。v1.9.4 修复闪卡「追加关键词=整章重生成」并新增**单卡重新生成**：`cards_cache` 关键词变更检测由整串 hash 一票否决改为**按关键词增量对账**（追加新词只补生成新词、旧卡保留；删除关键词自动清对应卡），卡对象补存所属关键词（`kw`）；笔记保存时检测到新增关键词自动询问是否补生成；翻卡界面背面新增「🔄 重新生成这张卡」，质量差的卡单独重生（skip_cache 绕开一切旧缓存、该卡 SRS 记忆重置），不再为一张坏卡整章重烧 token；「📝 从笔记生成卡片」改为双分支——有新词=增量补生成、无新词=可选整章重生成；并统一全应用关键词分隔符口径（含「、」）。

- **线上地址**：https://dogeangle-gis.hf.space
- **面向用户**：GIS/遥感专业考研、期末复习学生
- **教材来源**：GIS（田永中《地理信息系统》）+ 遥感（周廷刚《遥感原理与应用》）

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 单文件 HTML/CSS/JS | 无框架，所有代码在 `static/index.html` |
| Markdown 渲染 | marked.js + KaTeX (CDN) | Markdown + LaTeX 渲染 |
| 后端 | Python FastAPI + Uvicorn | 薄代理层 + 用户数据同步 |
| AI 服务 | 阿里云百炼 DashScope | RAG 应用，已配置专业课教材知识库 |
| 部署 | Hugging Face Spaces + Docker | Docker SDK 模式，自动构建 |
| 客户端存储 | localStorage（12+ 个 key） | 浏览器本地持久化 |
| 服务端缓存 | JSON 文件 | `answer_cache.json`（AI 回答缓存） |
| 用户数据 | JSON 文件 | `user_data/{user_id}.json`（跨端同步） |

### 闪卡生成策略（v1.3 / v1.9.4）

- **串行单关键词**：每个关键词单独请求，RAG 精准检索，消除"知识库未提供"
- **简答题标准**：答案按简答题标准作答，要点完整（3-5 句）
- **自动重试**：失败自动重试（最多 2 次，指数退避）
- **逐关键词追踪**：`kwDone` 只标记实际生成了卡片的关键词，失败的下次重试
- **增量对账（v1.9.4）**：关键词变更不再整章作废——追加新词只补生成新词（旧卡保留），删除关键词自动清对应卡；保存笔记检测到新词时询问是否立即补生成
- **单卡重新生成（v1.9.4）**：翻卡界面背面「🔄 重新生成这张卡」，质量差的卡单独重生（卡对象存 `kw` 定向定位，`skip_cache` 绕开旧缓存，该卡 SRS 记忆重置），无需整章重烧 token

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | AI 对话代理（`{messages, skip_cache?, purpose?}` → `{answer, cached}`；v1.9.3 起 `skip_cache:true` 不写缓存，`purpose` 打用途标签） |
| POST | `/api/sync/upload` | 上传用户数据（`{user_id, data}` → `{status, size}`） |
| GET | `/api/sync/download` | 下载用户数据（`?user_id=xxx` → `{status, data}`） |
| GET | `/api/cache` | 查看缓存信息（v1.9.3 起返回 `{total, purposes, keys}` 按用途计数） |
| DELETE | `/api/cache` | 清空服务端缓存；可选 `?purpose=xxx` 只清该用途（v1.9.3） |
| GET | `/api/health` | 健康检查 |
| GET | `/` | 前端页面 |
