# GIS-Review v1.9 — 专业课 AI 复习助手

GIS（地理信息系统）和遥感专业课的智能复习应用。基于阿里云百炼 DashScope RAG 平台，以教材知识库为后盾，提供 AI 问答、闪卡记忆、自动出题、模拟考试、学习统计、跨端同步等功能。v1.5 新增**正反馈庆祝系统**：闪卡积分/连击、满分庆祝、每日任务、达标与里程碑庆祝、音效（可关）。v1.6 新增**自定义 Prompt 编辑器**：在「我的」页可整段改写全部 AI 提示词（问答/闪卡/判题/出题/冲刺/指南），占位符运行时替换，可一键恢复默认并随云端同步。v1.7 修复「我的」页数据安全与统计正确性：同步时间戳体系修复（杜绝下载静默覆盖本地新数据）、覆盖确认反转、全部本地数据解析崩溃防护、年份视图/跨午夜结算/每日目标级联修正、闪卡缓存不再上云，并修复徽章触发逻辑（章节徽章按真实掌握率触发、连胜里程碑兼容老数据）。v1.8 新增**记忆衰退系统**：完成度随时间按遗忘曲线回落（第 N 轮 7/14/28/56/90 天封顶），复习推进轮次、轮次越高衰退越慢；衰退词重答即时巩固反馈，章完成庆祝与轮次里程碑徽章（第 3/7/10 轮）。v1.9 修复「我的」页计时与今日学习：学习时长秒表秒级落盘（刷新后从原秒数续计，不再退回整分）、跨天/刷新后不再归零、今日学习与每日任务「学习 N 分钟」进度恢复正常；并为记忆衰退系统新增**手动「再来一轮」**——学习进度页每章可一键清空该章掌握进度（轮数保留），重新掌握到 80% 即晋升下一轮，不再苦等 7 天衰退。另修复 v1.7 引入的 safeJSON 缺失 key 返回 null 的潜在崩溃。

- **线上地址**：https://dogeangle-gis.hf.space
- **面向用户**：GIS/遥感专业考研、期末复习学生
- **教材来源**：GIS（田永中《地理信息系统》）+ 遥感（周廷刚《遥感原理与应用》）

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 单文件 HTML/CSS/JS | 无框架，所有代码在 `static/index.html` |
| Markdown 渲染 | marked.js + KaTeX (CDN) | Markdown + LaTeX 渲染 |
| 后端 | Python FastAPI + Uvicorn | 薄代理层 + 用户数据同步 |
| AI 服务 | 阿里云百炼 DashScope | RAG 应用，已配置专业课教材知识库 |
| 部署 | Hugging Face Spaces + Docker | Docker SDK 模式，自动构建 |
| 客户端存储 | localStorage（12+ 个 key） | 浏览器本地持久化 |
| 服务端缓存 | JSON 文件 | `answer_cache.json`（AI 回答缓存） |
| 用户数据 | JSON 文件 | `user_data/{user_id}.json`（跨端同步） |

## 功能列表

### 核心功能

| 功能 | 说明 |
|------|------|
| AI 智能问答 | 基于教材知识库的 RAG 问答，支持上下文对话 |
| AI 出题 | 按章节/题型出题，标注关键词用于进度追踪 |
| 自动评分 | AI 阅卷，1-5 星评分 + 标准答案 + 采分点分析 |
| 闪卡记忆 | 从笔记关键词串行生成闪卡，SRS 间隔重复 |
| 模拟考试 | 从历年真题随机抽题，模拟考场环境 |
| 真题练习 | 历年真题按年份/题型分类练习 |
| 正反馈系统 | 闪卡 +2 积分/连击 combo/轮次总结/里程碑，答题逐星点亮/满分庆祝/连对加成/攻克薄弱点提示，每日任务三连与达标庆祝，音效可关（v1.5） |
| 自定义 Prompt | 「我的」页整段编辑全部 AI 提示词，`{占位符}` 运行时替换，每字段可恢复默认，随云端同步（v1.6） |
| 记忆衰退系统 | 完成度按遗忘曲线回落（第 N 轮 7/14/28/56/90 天封顶），复习推进轮次、轮次越高衰退越慢；衰退词 ⚠ 标注 + 一键复习；巩固即时反馈 +2 分、章完成 +5×N 分、轮次里程碑徽章；🔄 手动「再来一轮」清空该章进度、重达 80% 晋升下一轮（v1.8/v1.9） |

### 学习进度系统

| 功能 | 说明 |
|------|------|
| 关键词掌握追踪 | 答题 ≥4 星自动标记掌握 |
| 加权出题 | 已掌握关键词降低出题概率（权重 0.5），未尝试最高（权重 5.0） |
| 关键词统计 | 总关键词/已掌握/待巩固/未开始 四维度展示（v1.8 起按有效掌握率，衰退词计入待巩固） |
| 预估完成时间 | 全局平均 + 定期校正（每 7 天或每掌握 10 个） |
| 学习热力图 | GitHub 风格日/月/年视图 |
| 薄弱点管理 | 自动收集薄弱知识点，一键针对性练习 |

### 闪卡生成策略（v1.3）

- **串行单关键词**：每个关键词单独请求，RAG 精准检索，消除"知识库未提供"
- **简答题标准**：答案按简答题标准作答，要点完整（3-5 句）
- **自动重试**：失败自动重试（最多 2 次，指数退避）
- **逐关键词追踪**：`kwDone` 只标记实际生成了卡片的关键词，失败的下次重试

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | AI 对话代理（`{messages, skip_cache?}` → `{answer, cached}`） |
| POST | `/api/sync/upload` | 上传用户数据（`{user_id, data}` → `{status, size}`） |
| GET | `/api/sync/download` | 下载用户数据（`?user_id=xxx` → `{status, data}`） |
| GET | `/api/cache` | 查看缓存信息 |
| DELETE | `/api/cache` | 清空服务端缓存 |
| GET | `/api/health` | 健康检查 |
| GET | `/` | 前端页面 |
