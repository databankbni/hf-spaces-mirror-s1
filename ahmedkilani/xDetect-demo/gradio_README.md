# xDetect — Multilingual AI-Generated Text Detector

Detects whether text was written by a human or generated by an AI.

Supports **English**, **German**, and **Arabic**.

## Architecture
- Backbone: XLM-R-base (270M parameters)
- Adapters: LoRA adapters (r=16) for German and Arabic
- Training data: MultiTuDe v3 (matched generator suite across all languages)
- Backbone AUROC: EN=0.9958 | DE=0.9950 | AR=0.9905
