# 造神引擎GPT版：夥伴與 RPA 本機驗收

## 啟動網站

雙擊 `啟動本機預覽.bat`，瀏覽器會開啟 `http://127.0.0.1:8800/login`。

本機測試帳號：`wayne`、`partnera`、`partnerb`、`partnerc`  
本機初始密碼：`1234`

正式部署前必須以環境變數 `ZAOSHEN_BOOTSTRAP_PASSWORD` 設定新密碼，並設定 `SESSION_SECRET`。

## 驗收共同活動權限

1. 分別登入 partnera、partnerb、partnerc。
2. 每個帳號都能看活動總覽、3D 戰情室、全部內容、排程、名單與其他夥伴的裝置工作狀態。
3. 密碼、Facebook Cookie、裝置 token 和 API 密鑰不會顯示在共同頁面。

## 驗收 RPA 在線狀態

1. 登入後進入「夥伴與 RPA 裝置」。
2. 按「下載 Windows RPA」並解壓縮。
3. 按「產生配對碼」。
4. 雙擊 ZIP 裡的 `啟動造神引擎RPA.bat`。
5. 在 RPA 視窗輸入網站網址、裝置名稱及配對碼，按「配對裝置」。
6. 按「啟動 RPA」。約 20 秒內網站顯示「在線／待命」。
7. 按「停止」。停止心跳超過 65 秒後，網站顯示「離線」。

目前維持安全模式：RPA 可以配對、心跳、領取任務及開啟填稿，但不會自動按下 Facebook 發布。
