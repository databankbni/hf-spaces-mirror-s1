Reads `board.json` from the public
[nttd dataset](https://huggingface.co/datasets/deepsai8/nttd-submissions). The page holds
no token, verifies nothing, and cannot write: every row was decided by the verification
job in the board's repository.

Package with `nttd package`, then open a pull request adding your bundle to that dataset.
